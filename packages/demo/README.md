# auth-vir demo

Run the demo with the following steps:

1. clone the mono-repo
2. run `npm ci` at the root of the mono-repo
3. run `cd packages/demo`
4. run `npm start`
5. open the logged frontend URL in a browser
6. sign up with a username and password

Note that this demo has no persisted database, all created users are only stored in memory (so killing or restarting the demo server will wipe all created users).
